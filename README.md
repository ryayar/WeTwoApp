# WeTwo for Android: APK mirror

This repository only distributes the Android installer of WeTwo (https://wetwo.app). It contains no source code.

- `wetwo-latest.apk` is the current version.
- `wetwo-<version>-<build>.apk` is the same file under its version name.

Install only files from the official app or this mirror: the app checks the SHA-256 and the signature before installing.
